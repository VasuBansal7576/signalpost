# Blind saved-source semantic review

This review tests facts available in the preserved readable source corpus for all 1,000 companies. It is separate from the source acquisition benchmark and does not change the original databases or answers. Reference generation reads registry identity and saved source text, and deliberately does not read the published company profiles. Only after the company reference files are persisted does the comparison stage open published answers.

The independent reviewer uses `gpt-6-sol` through the existing local Codex subscription, without tools, paid APIs, Exa, Firecrawl, external API keys, or new website requests. It uses a different model and prompt from the production Luna extractor. The reviewer sees all readable sources regardless of the production source-attribution decision. This can expose facts excluded before extraction, as well as passages omitted by the production 16 KB packet. It records verbatim quotes, source IDs, exact identity evidence, publisher type, parent/group versus legal-entity binding, postal/property/operating-site scope, and dated versus undated activity or hiring.

Each company has a source manifest listing preserved hashes, included and omitted bytes, deduplicated identical texts, and truncation. The initial independent packet budget is 96 KiB of source text per company, distributed proportionally across every unique readable page; long pages retain both their beginning and end. A separately journaled residual phase splits **every omitted middle** into at most 80 KiB chunks, repeats surrounding identity context, and records the exact source-byte intervals reviewed. Its plan and summary distinguish initial omissions from any intervals still awaiting review. This prevents a small model context from silently excluding source text. A model seeing a span still does not establish that it noticed or correctly interpreted every fact in it. No readable page and no supported claim are **unknown states, never negative gold**. All calls have durable pre-call attempts and post-call receipts with tokens, cache usage, response ID, timing and API-equivalent prices; uncertain attempts are not automatically repeated. Subscription fees, hardware and operator time are excluded from the API-equivalent measure.

This is an assisted semantic reference, not independent human gold, an official score, or exhaustive web recall. A model may miss or misinterpret facts. Verbatim quote anchoring establishes that quoted words exist in the source; it does not prove that a fact belongs to the target. The reviewer explicitly flags uncertain or group/other-entity facts. Candidate comparisons require semantic inspection because differently phrased descriptions and subset location values can represent the same fact. Registry addresses found on an official registry webpage do not establish additional operating-office recall.

Artifacts are written under [`out/semantic-verification/corpus/`](../out/semantic-verification/corpus/). Full-semantic matching remains gated on complete reference generation and source-span accounting; the SDK comparison script has not been run.
