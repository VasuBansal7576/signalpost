## Repairs

- Explicit `--evaluator` execution accepts arbitrary cohort sizes without development quality certificates, skips local `.env` loading, and retains semantic publication checks across supported model providers. Normal development admission is preserved. Runtime authentication still needs organizer validation.
- One claim-date cutoff is checked at publication, including fresh, cached, saved and directly verified proposals. Invalid cutoffs fail early. This does not turn live undated pages into historical evidence.
- Completed unpaid continuation receipts are reused on ordinary reentry without enabling any new request; the original pending receipt is retained.
- Extraction completion is determined per admitted packet; a partial aggregate cannot shortcut reentry. The packet plan is bound to the extractor, prompt, policy, model, cutoff and output limit. Uncertain calls are not automatically repeated.
- Measured extraction and semantic-review token usage settle conservative TPM reservations. Missing usage cannot become complete zero-dollar API billing; envelope cost completeness includes incomplete model usage.
- Malformed workplace collections fail explicitly instead of becoming observed zero workplaces. Valid explicit-zero collections remain observed absence. Pagination beyond the existing declared completeness flag is not newly implemented.
- Quality fingerprints include provider routing and credential presence without serializing secrets.
- Public leadership evidence uses a labelled normalized projection, independent hash and original snapshot/hash lineage. Supporting evidence uses the projection too; raw role responses remain private. The dashboard source endpoint rejects original role responses. This is a privacy-minimization improvement, not an asserted explicit challenge prohibition.
- Bounded raw semantic output is retained privately before structured validation, tied to the exact attempt, source packet and hash. Only complete matching receipts can recover publication decisions without another model call. Missing, partial, tampered or changed-packet receipts fail closed. Excluded candidates remain private diagnostic records and cannot re-enter published facts.
- Immutable NAV catalogue validation/fingerprinting is reusable. Cached content is frozen so reference mutation cannot silently change the content behind a verified fingerprint. Company query results are still recomputed for their employer/subunit IDs and source cutoff.
- Synthesis retains every supported business-description statement and its qualification, with all corresponding evidence IDs.

The original GT failed semantic response was not retained by its historical code. No repair can reconstruct its actual judgments. The existing code's per-claim semantic counterquote handling was already improved before this isolated repair; it is not counted as a new fix here.

## Implemented architecture

- Registry, acquisition, extraction and semantic review have independent FIFO stage queues. Queue count and measured payload bytes are bounded; oversized prepared payloads spill by canonical hash into private SQLite. A shared abort-aware provider gate bounds inference/search calls. Stage entry renews only remaining active company time, with the global deadline still authoritative; queue residence does not consume active work time.
- Sealed evidence views and identity results use bounded generation-keyed caches. SQLite mutation triggers invalidate source/host generations. NAV validation is keyed by catalogue revision. Preserved archival source text, hidden text, PDFs and counterevidence remain available.
- Evidence blocks retain original offsets. Resource URLs are omitted only from the navigation appendix, not from archived sources. Semantic wire encoding shares duplicate long lines and quote/value text while retaining every factual/counterevidence page; full-source encoding is chosen when smaller. No relevance-based page pruning was added.
- Per-profile hashed append-only checkpoint segments replace repeated cumulative exports. A segment is registered before its first row. Interrupted SQLite profiles can backfill a new segment; an empty completed replay leaves its existing manifest byte-for-byte unchanged. SQLite remains authoritative and final output preserves input order.
- Replay preserves historical operations/timestamps and exact source-bound assisted review context while recomputing terminal status and synthesis. Public role projection retrieval time remains the original source time, with a separate derivation time. Cached retry and unpaid-continuation 404/410 receipts are no longer masked by an earlier aborted or pending first attempt.
