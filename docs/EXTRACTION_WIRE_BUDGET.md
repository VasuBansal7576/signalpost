# Bounded extraction wire and packet budget

Version v10 replaces duplicated model `value`/`quote` strings with one exact quote and a short packet source ID. The application reconstructs the full Proposal and ledger quote locally. Website/profile values can use a bounded ASCII URL only when it is the source URL or appears literally in that quote; ordinary facts use the quote as value. Existing ownership, cutoff, exact-span and independent semantic checks remain in force.

The14,000-byte default stream cap and30-second call deadline remain unchanged. A conservative per-claim budget counts worst-case JSON escaping (six bytes per UTF-16 quote unit),512URL bytes and512metadata/layout reserve; a512-byte envelope reserve applies. At500quote characters, default output admission permits three claims per packet. Default input packets decrease48KB→12KB, with overlap, full admitted/omitted/uncompleted span accounting and max32packets unchanged. These constraints can omit useful inventory; they are declared resource bounds, not proof of complete fact recall. Canonical compact schema-valid content fits the budget; a provider can still violate JSON/schema/minified-layout instructions, and the streamed cap remains fail-closed. Never raise the cap implicitly or replay uncertain calls.

Completed bounded JSON is validated per claim so one malformed item does not erase independent valid siblings. Rejection events record bounded reasons. Raw transient model output is not exported. Previously completed packets survive a later timeout/cap failure, with uncompleted coverage and uncertain usage retained. Cache/extraction-plan version v10 prevents v9 outputs being silently treated as fresh new-wire results.

Offline tests cover worst-case escaping/Unicode-style bounds, exact quote reconstruction, unrelated/detached refs, quoted outbound website declarations, malformed siblings, actual inference parsing without whole-output loss, cap abort, and durable partial-packet/no-retry behavior. Live exposed saved-evidence validation is a separate development experiment, not independent quality certification.
