# Public reputation opportunity audit

This is an independent extension to the 1,000-company semantic audit, not a claim of official challenge qualification or exhaustive web recall. The challenge's starter/reference material explicitly covers ratings, reviews, and qualified independent sentiment. Company promotional testimonials, financial risk scores, generic platform ratings, and search-result URLs cannot satisfy that family.

## Parser contract

`parsePublicReputation(rawSnapshot, readableSnapshot, targetIdentity, reviewedPolicy)` returns either supported observations with exact proof offsets and hashes, or blocked/unavailable/ambiguous with an empty observation list. Merchant organisation number and normalized legal name must both match the registry identity; merchant ID, merchant name, URL and JSON-LD Restaurant subject must agree. Aggregate and merchant state values/counts must agree. Multiple merchant scripts or legal imprints are rejected. Data is parsed without JavaScript execution. Raw and readable source hashes are recomputed. Source observation time is distinct from an individual review's publication date; no aggregate rating date is invented. No overall sentiment label is inferred.

`reputationPolicyKey` binds source origin, terms URL/hash, robots hash and decision. A caller must persist that policy receipt separately from observation evidence. No automatic source-policy approval is provided. The adapter has five offline tests covering supported synthetic records, missing/blocked policy, wrong entity or rating scope, altered evidence, and script injection/undefined parsing.

## All-company opportunity coverage

`scripts/semantic-reputation-discovery.ts` adds exactly one distinct reputation/independent-press search intent per company using the existing Codex subscription, with six native workers, durable exclusive pending receipts, complete raw response/usage receipts, and no retries of uncertain calls. It stops new admissions on provider access/quota errors. Public source retrieval is separately bounded, DNS pinned, robots checked, and uses the existing SignalpostResearch user agent. Pages are quarantined until individual terms, legal entity and independent publisher adjudication; a successful HTTP response or search URL is never publication evidence.

The existing corpus inventory covers all 1,000 organisations. Counts of candidate matches are search aids, not semantic recall or admitted reputation facts. New discovery writes compatible gzip page artifacts, company records and an isolated SQLite store under `out/semantic-verification/published/reputation/discovery/`. Pending, blocked, unavailable, ambiguous and unreviewed sources remain unknown; no missing search result is promoted to a negative reputation assertion. Running totals and complete API-equivalent model/search costs are reported separately from the previous semantic review. No external keys, connectors or paid credits are used.

## Observed quota boundary and final state of this pass

At 2026-10-17 03:25 UTC, this additional pass received HTTP 429 and immediately stopped new native admissions. There are **123 completed one-query receipts, six uncertain in-flight calls, and 871 companies whose new reputation query was not attempted**. No failed, pending or uncertain call was retried. Read-only account usage reporting still allowed ordinary usage and showed 95% weekly use; this does not identify whether the 429 was specific to hosted search, temporary admission pressure, or another account limit. The existing native-search wrapper discards upstream response bodies; only the HTTP status survived the transport boundary, so the exact provider type/code/message cannot responsibly be reconstructed.

Only public retrieval from already completed receipts continued. The resulting isolated corpus has 129 company rows (including explicit uncertain search outcomes), 410 unique gzip page artifacts, 510 company-page memberships and 63 source-policy-related pages. These counts are collection opportunities, not admitted reputation facts or validated recall. This timing excludes prior saved-corpus scanning and subsequent manual policy adjudication. No model calls occurred after the 429 stop.
