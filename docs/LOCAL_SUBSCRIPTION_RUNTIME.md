# Local included-subscription runtime requirements

The eve0.79.1 chatgpt adapter is a local-development route. It invokes the installed Codex CLI as `codex app-server --stdio`, resolves the existing signed-in subscription through its normal broker, and sends the model request only after broker initialization. The broker must be able to initialize its SQLite runtime in the existing Codex home. A filesystem sandbox allowing only the project and temporary directories can prevent that startup even when `codex --version` succeeds.

On17October2026 the instrumented normal adapter failed inside the restricted sandbox with `failed to initialize sqlite state runtime under $CODEX_HOME`, broker exit1, and zero provider HTTP requests. The same new diagnostic, using approved normal execution permissions, completed a search in5.957s with one search action, response ID and10,700 total tokens. A fresh single-company GT Logistikk run then completed acquisition, extraction and separate semantic review in43.334s. Its profile remained partial; browser rendering was disabled and the shared NAV catalogue skipped for the bounded smoke.

This is an execution-context requirement rather than a model/account/quota fix. The source records bounded private error categories/status/socket codes and available response/usage metadata; authentication material is excluded. Approval was limited to each requested process. No permanent permission rule, global configuration change, credential copying, protected-history access or paid fallback was used. The application's source code cannot grant filesystem permissions to a caller. Start local runs through a host context already authorized to use the normal broker and its runtime state.

A container or remote evaluator needs its own organizer-supported provider credentials and runtime; personal subscription state is not part of this package. Clean Linux/evaluator authentication and fresh independent cohort quality remain separate qualification requirements. The API provider path performs the same separate semantic publication review, but its live organizer authentication is not established by local subscription tests.

Local developmental batch runs declare the evidence cutoff, source cache and frozen NAV catalogue separately. Reusing a public NAV snapshot produces exact-company/subunit observations at the snapshot time; it does not assert a newly downloaded feed or company-wide absence of hiring. Disabling browser rendering can reduce acquisition coverage and must be disclosed. Offline replay and a working provider smoke are not independent precision/recall certificates.
